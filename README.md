# Sentineled Doubly Linked List

This is a Python project I completed for my Data Structures course. I built a sentineled doubly linked list from scratch to better understand how nodes, pointers, iteration, and linked data structures work.

The implementation includes insertion, removal, retrieval, iteration, reversal, rotation, exception handling, and Big-O analysis.

This project helped me get much more comfortable working with `.next`, `.prev`, sentinel nodes, and how linked lists operate internally.
